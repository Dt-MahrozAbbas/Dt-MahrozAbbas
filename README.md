### 🧠 About Me

I'm a **Data Science graduate (2026)** who builds AI/ML systems end-to-end — from RAG pipelines and LangGraph agent workflows to the backend infrastructure and vector databases that keep them running in production. I care about **self-hosted, cost-efficient AI** as much as model quality: if it can run without an API bill and a vendor lock-in, I'd rather build it that way.

- 🔭 Currently exploring **LLM fine-tuning, agentic workflows (LangGraph), and self-hosted inference** with `llama.cpp`
- 🏗️ Recently built a full **Docker-based local AI infrastructure stack** — LLMs, vector search, OCR, and storage, all self-managed
- 📚 B.S. Data Science @ **Punjab University College of Information Technology (PUCIT)**, Lahore
- 🎯 Looking for **AI/ML Engineer** roles where I can grow from strong backend foundations into production ML systems
- ⚡ Fun fact: I'd rather self-host a model on a spare GPU than pay for another SaaS subscription
